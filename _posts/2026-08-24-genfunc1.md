Hello everyone! <br>
It seems like the `XOR` thing has to wait for a bit. In the meantime, let's talk about something else: **generating functions**. If you've never seen them before, they might seem like a magic trick at first. This post is a prequel to a more advanced discussion, but before we get there, we need to understand generating functions.

---

## The Core Idea: A Sequence Wearing a Disguise

Suppose you have an infinite sequence of numbers:

{% include code_block.html content="a₀, a₁, a₂, a₃, ..." %}

A **generating function** is just this sequence, repackaged as the coefficients of a power series in a dummy variable `x`:

{% include code_block.html content="A(x) = a₀ + a₁x + a₂x² + a₃x³ + ..." %}

That's it. That's the whole idea. `x` isn't meant to be plugged in with a number, in fact don't even worry about whether this series "converges." Treat `x` as a bookkeeping symbol whose *only* job is to sit next to `aᵢ` and mark which term of the sequence we're talking about.

**Key insight:** We've converted a sequence (an infinite list of numbers) into a single algebraic object (a function). And algebraic objects can be added, multiplied, and manipulated using ordinary algebra. This is the entire value proposition: sequence problems become algebra problems.

---

## Turning Recurrences into Equations

Let's use the simplest possible example: the Fibonacci-style recurrence.

{% include code_block.html content="a₀ = 0, a₁ = 1, <br>
aₙ = aₙ₋₁ + aₙ₋₂ for n ≥ 2 " %}

Define A(x) as,
{% include code_block.html content="A(x) = a₀ + a₁x + a₂x² + a₃x³ + ... " %}

The trick is to write down the recurrence for *every* `n ≥ 2` simultaneously, by multiplying it by `xⁿ` and summing over all of them:

{% include code_block.html content="$$$$\sum_{n \geq 2} a_n x^n = \sum_{n \geq 2} a_{n-1} x^n + \sum_{n \geq 2} a_{n-2} x^n$$$$" %}

Now we simplify each side until LHS looks like `A(x)`.

**Left side:**
{% include code_block.html content="$$$$\sum_{n \geq 2} a_n x^n = A(x) - a_0 - a_1 x$$$$" %}
(We're just removing the first two terms of the full series.)

**First term on right:**
{% include code_block.html content="$$$$\sum_{n \geq 2} a_{n-1} x^n = x \cdot \sum_{n \geq 2} a_{n-1} x^{n-1} = x \cdot \sum_{m \geq 1} a_m x^m = x(A(x) - a_0)$$$$" %}

**Second term on right:**
{% include code_block.html content="$$$$\sum_{n \geq 2} a_{n-2} x^n = x^2 \cdot \sum_{n \geq 2} a_{n-2} x^{n-2} = x^2 \cdot \sum_{m \geq 0} a_m x^m = x^2 A(x)$$$$" %}

Putting it together, and substituting `a₀ = 0, a₁ = 1`:

{% include code_block.html content="$$$$A(x) - x = x(A(x) - 0) + x^2 A(x)$$$$" %}

Every occurrence of `A(x)` is now a single unknown in an ordinary algebraic equation. Solve for it like you'd solve for `y` in `y - x = xy + x²y`:

{% include code_block.html content="$$$$A(x) = \frac{x}{1 - x - x^2}$$$$" %}

Take a moment to appreciate what just happened. An infinite sequence, defined by an infinite family of equations (one recurrence per `n`), collapsed into a single rational function of `x`. That closed form on the right, $$\dfrac{x}{1 - x - x^2}$$, *is* the Fibonacci sequence (in compact form). It contains every Fibonacci number, all at once, packed into one expression.

---

## A Second Example: A Non-Homogeneous Recurrence

Let's try one with an extra term tacked on:

{% include code_block.html content="a₀ = 1,<br>
aₙ = 2aₙ₋₁ + 1 for n ≥ 1" %}

Multiply by `xⁿ` and sum over `n ≥ 1`:

{% include code_block.html content="$$\sum_{n \geq 1} a_n x^n = 2\sum_{n \geq 1} a_{n-1} x^n + \sum_{n \geq 1} x^n$$" %}

Each piece:

- Left side: 
{% include code_block.html content="$$\sum_{n \geq 1} a_n x^n = A(x) - a_0 = A(x) - 1$$" %}
- First term: 
{% include code_block.html content="$$\sum_{n \geq 1} a_{n-1} x^n = x \cdot \sum_{n \geq 1} a_{n-1} x^{n-1} = x \cdot \sum_{m \geq 0} a_m x^m = x \cdot A(x)$$" %}
- Second term: 
{% include code_block.html content="$$\sum_{n \geq 1} x^n = \frac{x}{1-x}$$" %} (the geometric series, shifted to start at `n=1`)

So:

{% include code_block.html content="$$A(x) - 1 = 2x \cdot A(x) + \frac{x}{1-x}$$" %}

On simplying, we get:

{% include code_block.html content="$$A(x) = \frac{1}{(1-x)(1-2x)}$$" %}


---

## Extracting Coefficients Back Out

Having a closed form like `A(x) = 1/[(1-x)(1-2x)]` is nice, but we still want the actual numbers `a₀, a₁, a₂, ...`. The standard move is **partial fractions**: rewrite the expression as a sum of simpler pieces whose series expansions you already know.

{% include code_block.html content="$$\frac{1}{(1-x)(1-2x)} = \frac{A}{1-x} + \frac{B}{1-2x}$$" %}

Solving for `A` and `B` (clear denominators, match coefficients or plug in convenient values of `x`) gives `A = -1, B = 2`. So:

{% include code_block.html content="$$A(x) = \frac{-1}{1-x} + \frac{2}{1-2x}$$" %}

Now use the one series everyone should have memorized, the geometric series `1/(1-rx) = Σ(n≥0) rⁿxⁿ`:

{% include code_block.html content="$$A(x) = -\sum_{n \geq 0} x^n + 2·\sum_{n \geq 0} (2x)^n = \sum_{n \geq 0} (2·2^n - 1)x^n$$" %}

Reading off the coefficient of `xⁿ` gives the closed form directly:

{% include code_block.html content="$$a_n = 2^{n+1} - 1$$" %}

Check it: `a₀ = 2 - 1 = 1` ✓, `a₁ = 4 - 1 = 3 = 2(1) + 1` ✓, `a₂ = 8 - 1 = 7 = 2(3) + 1` ✓.
<br>It works.

---

## The General Recipe

Every one of these problems follows the same four steps:

1. **Write the recurrence** for the general term, multiply both sides by `xⁿ`, and sum over the valid range of `n`.
2. **Rewrite every sum** in terms of the full generating function `A(x)`, shifting indices as needed (this is where the `x`, `x²`, etc. multipliers come from).
3. **Solve the resulting algebraic equation** for `A(x)`. It's just one equation with one unknown, `A(x)` itself.
4. **Expand `A(x)` back into a power series** (often via partial fractions and known series like the geometric series) to read off a closed form for `aₙ`.

Steps 1-3 turn a recurrence into algebra. Step 4 turns the algebra back into numbers. Everything in between is just careful bookkeeping with sums.

---

## What You Now Know

- A generating function packages an entire sequence into one algebraic object, a power series where `x` is just a placeholder marking position.
- Multiplying by `xⁿ` and summing lets you convert a recurrence (infinitely many equations) into a single equation in `A(x)`.
- Partial fractions let you expand a rational generating function back into an explicit formula for `aₙ`.

---

That's the whole toolbox for now, just enough algebra to turn any recurrence relation into a rational function and back. <br><br>
