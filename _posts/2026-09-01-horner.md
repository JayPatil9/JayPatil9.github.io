Have you ever wondered how to evaluate a polynomial efficiently? Or how to compute its derivative at a point without doing any calculus? Or how to divide a polynomial by a linear factor without doing long division? The answer to all of these questions is the same: **Horner's method**.

---

## The Bottleneck: Evaluating a Polynomial the Obvious Way

Suppose you have a polynomial,

{% include code_block.html content="$$P(x) = a_0  +  a_1x  +  a_2x^2  +  a_3x^3  +  ...  +  a_nx^n$$"%}

and you want to compute `P(c)` for some value `c`.

The way most people first write this down looks something like:

```cpp
double evaluate_naive(vector<double>& a, double x) {
    double result = 0;
    for (int i = 0; i < (int)a.size(); i++) {
        double xi = 1;
        for (int j = 0; j < i; j++) xi *= x;
        result += a[i] * xi;
    }
    return result;
}
```
{% include run_it.html id="6a96a2045d7c5c32e56f0810" %}

For each term $a_i x^i$, we recompute $x^i$ from scratch by multiplying $x$ by itself $i$ times. Summed over all $i$ from $0$ to $n$, that's $0 + 1 + 2 + ... + n$ multiplications just to build the powers, which is **O(n²)**.

**Key insight:** the inefficiency isn't that we're doing multiplications, it's that we're doing *redundant* ones. $x^5$ and $x^4$ share almost all of their work, $x^5 = x^4 \cdot x$, but the code above throws away $x^4$ and starts over.

The obvious fix is to cache the previous power:

```cpp
double xi = 1, result = 0;
for (int i = 0; i < (int)a.size(); i++) {
    result += a[i] * xi;
    xi *= x;
}
```
{% include run_it.html id="6a96a99f5d7c5c32e56f0811" %}

This brings it down to **O(n)** multiplications, and if all you wanted was a linear-time evaluator, you're already done. But this version is still not optimized yet.

## Horner's Method:

Instead of thinking of `P(x)` as a sum of independent terms, factor an `x` out repeatedly:

{% include code_block.html content="$$P(x) = a_0 + x(a_1 + x(a_2 + x(a_3 + ... + x(a_{n-1} + x \cdot a_n)...)))$$" %}

Before you get lost in those parentheses, try to prove this for a small polynomial, like $P(x) = 1 + 2x + 3x^2$. <br>

This looks more cluttered at first glance, but notice what's happened: every `aᵢ` is used exactly once, and every multiplication is by the *same* `x`, nested inside the previous result. There are no powers of `x` floating around anywhere, just repeated "multiply by `x`, then add the next coefficient."

That reading translates directly into code:

```cpp
double horner(vector<double>& a, double x) {
    double result = a.back();                 // start with a_n
    for (int i = (int)a.size() - 2; i >= 0; i--) {
        result = result * x + a[i];
    }
    return result;
}
```
{% include run_it.html id="6a96aee15d7c5c32e56f0812" %}

**Exactly `n` multiplications and `n` additions.** No temporary powers, no wasted work, and the code is shorter than the "optimized" naive version above.

## Synthetic Division Is Horner's Method in Disguise

Here's an important fact. Watch what happens if you keep track of the intermediate `result` values while running Horner's method at `x = c`, instead of throwing them away:

```cpp
vector<double> b(a.size());
b.back() = a.back();
for (int i = (int)a.size() - 2; i >= 0; i--) {
    b[i] = b[i + 1] * c + a[i];
}
// b[0] is P(c). b[1..n] are the coefficients of the quotient.
```
{% include run_it.html id="6a96b5785d7c5c32e56f0813" %}

Those intermediate values `b[1], b[2], ..., b[n]` are exactly the coefficients of `Q(x)`, the quotient you get from dividing `P(x)` by `(x - c)`. And `b[0]`, the final answer, is the remainder of that division.

Feels like magic, but it's not. It's just the distributive property in action: every time you multiply by `c` and add the next coefficient, you're effectively "shifting" the polynomial down by one degree, which is exactly what happens when you divide by `(x - c)`.

Before we move on, I recommend you try this out with a small polynomial and a specific `c` on paper, to see how the coefficients of the quotient emerge naturally from Horner's method. <br>
And then visit the interactive demo given at the bottom of the code snippet to see it in action.

## Derivatives, Almost for Free

Grab your coffee, because this is the part that blew my mind when I first learned it. The derivative of a polynomial is just as easy to compute as the polynomial itself, using Horner's method.

Have you ever heard of dual numbers? They're a number system that extends the real numbers with an infinitesimal element `ε` such that `ε² = 0`. The key property is that for any smooth function `f`, we have:

{% include code_block.html content="$$f(x + \epsilon) = f(x) + f'(x)\epsilon$$" %}

It is obvious that if you evaluate a polynomial at `x + ε`, the coefficient of `ε` in the result is exactly the derivative at `x`. And since Horner's method evaluates polynomials efficiently, we can use it to compute derivatives efficiently as well.

Let's modify our Horner's method to work with dual numbers. Instead of just keeping track of the value of the polynomial, we also keep track of the derivative:

Let the answer at `(i-1)th` iteration be a dual number `p + dε`.

Usually, we do this for next iteration:
{% include code_block.html content="$$p = p \cdot c + a_i$$" %}
But now we do this:
{% include code_block.html content="$$p + d\epsilon = (p + d\epsilon) \cdot (x + \epsilon) + a_i$$" %}

which expands to:
{% include code_block.html content="$$p + d\epsilon = p \cdot x + p \cdot \epsilon + d \cdot x \cdot \epsilon + a_i$$" %}

i.e. we update `p` and `d` as follows:
{% include code_block.html content="$$p = p \cdot x + a_i$$ <br> $$d = d \cdot x + p$$" %}

Implementing this in code is straightforward:

```cpp
#include <iostream>
#include <vector>

using namespace std;

// Evaluates polynomial and its derivative using Horner's method with dual numbers
// coeffs: coefficients of the polynomial in descending order of power
// x: the value to evaluate the polynomial at
// Returns a pair: {P(x), P'(x)}
pair<long long, long long> evaluate_with_derivative(vector<long long>& coeffs, long long x) {
    if (coeffs.empty()) return {0, 0};

    long long p = coeffs[0]; // Real part (Accumulates P(x))
    long long d = 0;         // Dual part (Accumulates P'(x))

    for (int i = 1; i < coeffs.size(); ++i) {
        // d_new = d*x + p
        d = (d * x) + p;
        
        // p_new = p*x + a_k
        p = (p * x) + coeffs[i];
    }

    return {p, d};
}

void solve() {
    // P(x) = 3x^2 + 2x + 1
    vector<long long> coeffs = {3, 2, 1};
    long long x = 2;

    pair<long long, long long> result = evaluate_with_derivative(coeffs, x);

    cout << "Evaluating at x = " << x << "\n";
    cout << "P(x)  = " << result.first << "\n";
    cout << "P'(x) = " << result.second << "\n";
}

int main() {
    solve();
    return 0;
}
```
