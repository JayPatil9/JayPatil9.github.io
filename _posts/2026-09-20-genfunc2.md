Hello again!

In the [last post](/genfunc1), every recurrence we solved had its initial values pinned at the start:  `a₀`, `a₁`, ... and the rest built forward from there. That's the easy case: once you know where the sequence begins, the generating function equation gives you everything.

This time we look at a genuinely different setup: a **boundary value problem**. The recurrence still ties three consecutive terms together, but instead of knowing the first two terms, we only know the values at the two *ends* of a finite sequence, and we have to recover everything, including the values just inside those boundaries, from the generating function itself.

---

## The Setup

Consider a sequence `u₀, u₁, …, u_N` satisfying

$$a u_{n+1} + b u_n + c u_{n-1} = d_n, $$

$$n = 1, …, N-1 \quad \& $$

$$u_0 = u_N = 0$$

where `a`, `b`, `c` are known constants and `d₁, …, d_{N-1}` is a known sequence. Notice what's missing: we're never told `u₁` directly. We only know the sequence vanishes at both ends. Three adjacent terms appear in the recurrence, so getting it started needs *two* adjacent values, and neither `u₀` nor `u₁` is handed to us outright (only `u₀ = 0` is).

Define the generating functions

{% include code_block.html content="$$U(x) = \sum_{j=0}^{N} u_j x^j \quad (\text{unknown})$$" %}
<p style="margin-bottom: 0.5em;"></p>
{% include code_block.html content="$$D(x) = \sum_{j=1}^{N-1} d_j x^j \quad (\text{known})$$" %}

`U(x)` is a genuine polynomial here, not an infinite series, the sequence only runs from `0` to `N`. That finiteness is going to matter later.

---

## Setting Up the Equation

Multiply the recurrence by `xⁿ` and sum over `n = 1, …, N-1`:

{% include code_block.html content="$$a\sum_{n=1}^{N-1} u_{n+1}x^n + b\sum_{n=1}^{N-1} u_n x^n + c\sum_{n=1}^{N-1} u_{n-1}x^n = \sum_{n=1}^{N-1} d_n x^n$$" %}

Simplify each piece.

**First term:**

{% include code_block.html content="$$a\sum_{n=1}^{N-1} u_{n+1}x^n = \frac{a}{x}\sum_{n=1}^{N-1} u_{n+1}x^{n+1} = \frac{a}{x}\big(U(x) - u_0 - u_1 x\big) = \frac{a}{x}\big(U(x) - u_1 x\big)$$" %}

(using `u₀ = 0`.)

**Second term:**

{% include code_block.html content="$$b\sum_{n=1}^{N-1} u_n x^n = b\big(U(x) - u_N x^N - u_0\big) = b\,U(x)$$" %}

(both boundary terms vanish here.)

**Third term:**

{% include code_block.html content="$$c\sum_{n=1}^{N-1} u_{n-1}x^n = xc\sum_{n=1}^{N-1} u_{n-1}x^{n-1} = xc\big(U(x) - u_{N-1}x^{N-1} - u_N x^N\big) = xc\big(U(x) - u_{N-1}x^{N-1}\big)$$" %}

(again, `u_N = 0` kills the last piece.)

Putting the left side together:

{% include code_block.html content="$$\frac{a}{x}\big(U(x) - u_1 x\big) + b\,U(x) + xc\big(U(x) - u_{N-1}x^{N-1}\big) = D(x)$$" %}

Multiply through by `x` to clear the fraction:

{% include code_block.html content="$$a\big(U(x) - u_1 x\big) + bx\,U(x) + x^2 c\big(U(x) - u_{N-1}x^{N-1}\big) = xD(x)$$" %}

Collect every `U(x)` term on one side:

{% include code_block.html content="$$U(x)\big(a + bx + cx^2\big) = xD(x) + au_1 x + cu_{N-1}x^{N+1} = x\Big(D(x) + au_1 + cu_{N-1}x^{N}\Big)$$" %}

so

{% include code_block.html content="$$U(x) = \frac{x\big(D(x) + au_1 + cu_{N-1}x^{N}\big)}{a + bx + cx^2}$$" %}

Above is a closed form for the generating function, but it still contains the two unknowns `u₁` and `u_{N-1}`. The next section shows how to recover them.

Take a deep breath, and go through this section once again. Since this is going to be the baseline for (~~main~~)one of the climax of this series.

---

## Recovering the Missing Values

`U(x)` is a **polynomial**, a finite sum, `u₀ + u₁x + ... + u_N x^N`. Polynomials don't have poles. So wherever the denominator `a + bx + cx^2` hits zero, the whole expression would blow up to a value where we know it can't. So, ...

Let `γ₊` and `γ₋` be the two roots of

$$a + bx + cx^2 = 0$$

(assumed distinct, so `γ₊^N ≠ γ₋^N`). Plugging each root into the numerator and setting it to zero gives two linear equations in the two unknowns:

$$au_1 + c\,\gamma_+^{\,N}\,u_{N-1} = -D(\gamma_+)$$

$$au_1 + c\,\gamma_-^{\,N}\,u_{N-1} = -D(\gamma_-)$$

Two equations, two unknowns (`u₁` and `u_{N-1}`), solve the linear system and you have both missing values.

Substitute those back into the expression for `U(x)` above, and the generating function is **completely determined**. Expanding it back into a series (or just reading off coefficients) hands you every `u` in the sequence.

---

## Why This Feels Different

The two-term and plain three-term cases handed you a starting value for free, and the generating function equation did the rest. Here, the boundary conditions `u₀ = u_N = 0` don't give you enough to get started, they only constrain the *ends*. The trick that rescues us is a fact that's easy to overlook: **a finite sequence's generating function is a polynomial.** That single observation is what lets us extract the two missing interior values, turning an underdetermined-looking setup into a fully solved one.
